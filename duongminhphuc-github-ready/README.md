# Portfolio Dương Minh Phúc

Bộ website tĩnh sẵn sàng để đưa lên GitHub Pages.

## Cấu trúc

```
index.html
favicon.svg
images/
  avatar.png
```

## Thay ảnh đại diện

Thay file `images/avatar.png` bằng ảnh thật của bạn và giữ nguyên tên `avatar.png`.

## Đưa lên GitHub Pages

1. Tạo repository `USERNAME.github.io` trên GitHub.
2. Upload toàn bộ nội dung trong thư mục này vào thư mục gốc của repository.
3. Vào **Settings > Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main` và folder `/(root)`, sau đó Save.

## Form liên hệ

Form dùng FormSubmit và gửi về `minhphucduong21@gmail.com`.

Sau khi website đã online, hãy gửi thử form lần đầu. FormSubmit sẽ gửi một email xác nhận/activation tới địa chỉ trên. Bạn cần bấm xác nhận một lần trước khi các tin nhắn tiếp theo được chuyển vào hộp thư.

Lưu ý: FormSubmit có thể không hoạt động khi mở `index.html` trực tiếp bằng `file://`; hãy kiểm tra sau khi website đã chạy trên GitHub Pages hoặc một web server.
